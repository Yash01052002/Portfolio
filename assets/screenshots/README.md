# Add authentic application screenshots

The ZIP contains **no verified project screenshots**. The bundled SVGs are illustrative concepts and are labeled as such.

Export actual captures of your applications as WebP and save here:

BlackBox: `blackbox-01.webp`, `blackbox-02.webp`, `blackbox-03.webp` (e.g. crash dashboard, symbolized trace, diagnosis)
Suraksha: `suraksha-01.webp`, `suraksha-02.webp`, `suraksha-03.webp` (e.g. SOS screen, trusted contacts, location/permissions)
Support Ticket: `support-ticket-01.webp`, `support-ticket-02.webp`, `support-ticket-03.webp` (only features genuinely built; project is in progress)

Use ~1200x900 pixels or larger; redact tokens, API keys, phone numbers, location and other sensitive information. The site automatically replaces each corresponding concept image and updates the count when an actual file loads. You can provide fewer than three screenshots per project.

For videos, see `assets/videos/README.md`.
