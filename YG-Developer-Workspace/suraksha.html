THE CASE STUDY / 02

The challenge

In an urgent situation, people need a fast way to notify trusted contacts and share location information. Suraksha explores an Android-first safety flow that reduces the steps between recognizing a problem and sending an alert.

My approach

I built a Flutter application with emergency actions, trusted-contact workflows, location-sharing functionality, and supporting cloud services. The application brings those tools into a mobile-first interface.

Key features

  • SOS interaction intended for quick emergency escalation.
  • Shake-based alert flow to provide an alternate way to trigger an emergency action.
  • Location sharing and trusted-contact features.
  • Firebase-backed application features and Twilio-based alert integration.
  • Android packaging, with companion Wear OS work represented in the project.

Engineering decisions

The design prioritizes direct access to emergency actions, understandable status feedback, and a mobile experience where the most important controls remain easy to reach.

What I learned

Suraksha expanded my experience beyond web APIs into cross-platform UI, mobile device features, and integrations with external services.

This is a software project, not a substitute for emergency services or a certified safety system. The phone visual above is an illustrative recreation.
